# ViteOS
A webos that runs in the browser. Built for hackclub's stardance challenge.

---

### Features:
- Multiple draggable windows.
- Windows like interface.
- Clock app:
    - Analog clock
    - Digital clock
- Notes app:
    - Create multiple notes.
    - Full CRUD functionality available.
- Photos app

---

### Tech Stack:
- **Framework**: React,vite.
- **Styling**: TailwindCSS.
- **Deployment**: Vercel
